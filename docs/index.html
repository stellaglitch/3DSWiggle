3DSWiggle

A wigglegram camera for the Nintendo 3DS. Take a photo with the dual front cameras, select a focal point, and then save your wigglegram as a looping GIF!

Download .cia Download .3dsx Source on GitHub

How it works

01

Shoot

Both outer cameras shoot at the same instant, so your subject will stay still, while the scene moves around them.

02

Pick the pivot

Tap your subject with the touchscreen to set your focal point. The app auto-aligns the second photo on it. Fine-tune with the D-Pad, using the overlay view.

03

Save your GIF

Use the D-pad to adjust the speed of the wiggle, and add crossfade frames with the shoulder buttons. The A button saves the GIF to your SD card.

Install

You need a 3DS, 2DS or New 3DS (any model with two outer cameras) running custom firmware.

  1. CIA (recommended): download 3DSWiggle.cia and copy it to your SD card. Open FBI → SD → 3DSWiggle.cia → Install. 3DSWiggle appears on the HOME Menu.
  2. 3DSX: download 3DSWiggle.3dsx, copy it to sd:/3ds/, and launch it from the Homebrew Launcher.

GIFs are saved to sd:/wigglegrams/WIG_0001.gif, WIG_0002.gif, …

Build from source

The build runs in the official devkitpro/devkitarm container image, so you don't need a local devkitPro install. Use Linux or WSL with podman or docker.

git clone https://github.com/stellaglitch/3DSWiggle.git
cd 3DSWiggle
bash tools/build_cia_tools.sh   # one time: builds makerom + bannertool
bash build.sh                   # -> 3DSWiggle.cia and 3DSWiggle.3dsx

See the README for details and the PC test suite.
